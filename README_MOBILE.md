# 洪老师 AI 量化 v2.5.0（手机网页版）

这是移动端综合轮动版：在原100分规则评分、买卖点和持仓风控基础上，新增美股/韩国/日本隔夜联动、全球新闻线索、消费行业分类与消费专属质量因子。

## 手机端能做什么

- 今日候选 Top N 卡片
- 输入股票代码/名称查询
- 手机直接录入持仓
- 自动检查总仓、单票、单行业集中度
- 上传行情 CSV 后一键全市场评分
- 显示规则分、AI概率、建议首仓、ATR止损
- 首板/一进二仍使用独立 relay 模块
- 全球市场：道指、标普、纳指、费半、英伟达、AMD、美光、戴尔、韩国KOSPI/KOSDAQ、三星、SK海力士、日经
- 隔夜新闻线索：海外市场/美联储、韩国半导体、中国消费政策、大宗商品与汇率
- 消费行业：食品饮料、家电家居、零售电商、旅游酒店餐饮、美妆服饰珠宝、汽车、消费电子
- 消费股财务因子：ROE、净利润增速、营收增速、毛利率、存货周转、经营现金流（字段不足时不打分）
- 主板实时预筛采用行业分层，减少热门行业挤占全部深度扫描名额

## 一键本地启动

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 部署到 Streamlit Community Cloud

1. 把本目录上传到 GitHub 仓库。
2. 在 Streamlit Community Cloud 选择该仓库。
3. Main file path 填 `app.py`。
4. 部署完成后会得到一个 HTTPS 网页地址。
5. iPhone / Android 浏览器打开即可；可“添加到主屏幕”。

## 数据要求

最少字段：

`date,symbol,open,high,low,close,volume`

推荐补充：

`name,industry,amount,turnover_rate,market_cap,pe_ttm,pb,roe,net_profit_yoy,main_net_inflow,auction_open_ratio,auction_volume_ratio,is_limit_up,is_st`

数据越完整，行业/质量/资金/接力评分越有意义。系统不会伪造缺失字段。

## 全球市场评分口径

- 市场环境仍为20分：A股本地环境10分 + 全球隔夜环境10分。
- 全球环境：美股大盘2分、美股科技/半导体3分、韩国/日本2分、隔夜新闻/宏观3分。
- 新闻标题只作为线索；需要在“全球/消费”页人工确认偏多/中性/偏空，不直接让关键词自动决定买卖。
- 海外行情按各市场实际交易时间显示；休市时可能是上一交易日收盘价。
- 海外行情或新闻接口失败时显示缺失，不把缺失数据当成利空。

## 重要限制

当前网页本身不含券商交易接口，也不自动抓取同花顺私有盘口。它是“量化决策终端”，不是自动下单机器人。
